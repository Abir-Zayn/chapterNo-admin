## Important reading note

These documents describe the agreed product baseline and documented proposals, not proof that every feature is implemented. Items marked **Proposed**, **Discussed**, **Unresolved**, or **Future** require confirmation before implementation or public promises. Where a newer owner-approved decision conflicts with this pack, the newer explicit decision takes precedence.

## Product in one sentence

ChapterNo is a Bangladesh-first personal learning companion, initially focused on SSC students, that helps learners plan, learn, practise, identify mistakes, revise, and measure improvement.

## Core learning loop

**Plan → Learn → Practise → Review mistakes → Revise → Measure improvement**
